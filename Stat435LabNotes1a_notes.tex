\subsection{Samples from Gaussian
r.v.'s}\label{samples-from-gaussian-r.v.s}

Generate a sample from a Gaussian \emph{random variable (r.v.)}. Basic
syntax:

\begin{verbatim}
rnorm(n, mean = 0, sd = 1)
\end{verbatim}

\begin{itemize}
\tightlist
\item
  \texttt{n}: sample size
\item
  \texttt{mean} and \texttt{sd}: vector of means and vector of standard
  deviations
\end{itemize}

\emph{Note:} \texttt{mean} and \texttt{sd} can be specified by user.
